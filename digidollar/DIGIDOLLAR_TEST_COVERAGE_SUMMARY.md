# DigiDollar Test Coverage Summary

In the current DigiDollar branch, the full native test surface is **3,842 test entries**: **3,304 C++ unit test cases**, **324 functional test scripts**, and **214 fuzz targets**. The DigiDollar/oracle area accounts for **2,863 of those entries**, or about **74.5% of the total native test surface**. The remaining normal DigiByte/Core test surface is about **979 entries**. So by raw count, DigiDollar/oracle testing is almost **3x larger** than the rest of the non-DigiDollar test entries combined.

The biggest difference is in unit testing. There are **2,722 DigiDollar/oracle unit test cases** out of **3,304 total unit test cases**, which is about **82.4%** of all C++ unit test cases in this branch. The non-DigiDollar unit test surface is **582 unit cases**. That means DigiDollar has roughly **4.7x more unit test cases** than the rest of the normal DGB unit tests combined. These cover consensus validation, mint/redeem/send rules, lock tiers, collateral math, wallet state, RPC behavior, mining template rules, reorgs, parser safety, oracle bundles, MuSig2, P2P messages, and adversarial red-team cases.

Functional testing is also significant. There are **88 DigiDollar/oracle functional scripts** out of **324 total runnable functional scripts**, about **27.2%** of the functional suite. Normal DigiByte/Core has **236 non-DigiDollar functional scripts**. The DigiDollar functional tests cover actual node behavior: activation, wallet mint/redeem flows, transaction relay, mempool/miner parity, oracle pricing, stale oracle behavior, GBT mining support, reorgs, wallet restore/rescan/reindex, encrypted wallets, descriptors, and restart persistence.

For the safety systems specifically, the current tree has **142 DCA-related test entries**, **238 ERR-related test entries**, and **134 volatility-related test entries**. Those overlap, so the unique combined DCA/ERR/volatility coverage is **447 entries**: **415 unit test cases**, **20 functional scripts**, and **12 fuzz targets**. Oracle coverage is even larger, with about **1,542 oracle/MuSig2/bundle/quorum-related entries** across unit, functional, and fuzz testing. In simple terms: DigiDollar is not lightly tested. It has a larger dedicated test surface than normal DGB code in this branch, with especially heavy coverage around consensus safety, oracle correctness, emergency protection, volatility handling, mining templates, and wallet behavior.
